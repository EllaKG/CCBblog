# assets/

Place project media files here.

- `images/` - PNG, JPG, SVG, etc.
- `fonts/` - Custom web fonts (WOFF, WOFF2, TTF).
- `media/` - Audio, video, or other large assets.

Usage:
- Reference assets with relative paths from `index.html`, e.g. `assets/images/logo.png`.
- Keep filenames lowercase and use dashes for spaces (e.g. `my-image.png`).
mywebsite/
  index.html
  images/
    3T6A0993.jpeg
